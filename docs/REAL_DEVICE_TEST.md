# 実機テストチェックシート（Android / iPhone）

複数人で Android / iPhone の実機テストを同時に進めるためのチェックシート。

## 使い方

- 各項目の「Android」「iPhone」列に、テストした人がその場で書き込む。
  - `[ ]` 未実施 / `[x]` OK / `[!]` NG
- 「備考/不具合」には、NG の内容・端末機種・OS バージョン・再現手順・
  スクショの有無などを書く。テストした日付と担当者名も添えると後で
  追いやすい。
- iOS は 2026-09-18 時点で main に Firebase の iOS 設定が無く、ビルドしても
  ログインできない可能性がある（[仕様書.md](../仕様書.md) 11章）。ビルド
  すらできない場合は iPhone 列に `[!]` とその旨を書けばよい。
- この表はテスト結果を記録するためのものであり、テスト対象の仕様の
  詳細は [仕様書.md](../仕様書.md) と [README.md](../README.md) を参照。
